AUSTRALIAN ENGLISH DICTIONARY (AussieDic) - VERSION 3.1.0

SUMMARY
-------
Dictionary entries before: 501,395
Dictionary entries after:  361,348
The entry count is lower because duplicates and redundant entries were merged. Every correctly
spelt word accepted by version 3.0.1 is still accepted (checked with Hunspell against all
461,191 word forms the old file produced). The only words no longer accepted are the
misspellings and junk entries listed below.

WHAT WAS FIXED
--------------
Common misspellings removed (1568 entries)
The dictionary was accepting a large number of well-known misspellings as correct, which meant
Firefox would never underline them. Examples: recieve, definately, seperate, wich, untill, thier,
wierd, alot, noone, goverment, enviroment, accomodate, occured, begining, existance, tommorow.
Apostrophe-less contractions (dont, didnt, isnt, wouldnt, thats, theyre, youre and so on) were
also removed so they get flagged. The apostrophe versions (don't, didn't etc) still work.
Deliberate slang spellings were kept, including all dropped-g forms (goin, fallin, bleedin,
flippin), stoopid, bootup, reenable and legitimate Australian/British forms such as despatcher,
co-ordinate, pre-empt, pease and pastural.

Multi-word entries (528 entries)
Spell checkers test one word at a time, so entries containing a space (for example "Alice
Springs" or "Australian Capital Territory") could never match anything. These were split into
single words. Words that were not already in the dictionary were added:
Abels, Ansons, Antill, Batemans, Birchs, Blackmans, Bonnells, Bradys, Brittons, Sav, Calperum,
Connellys, Couta, Cudlee, Darke, Dennes, Edgcumbe, Geilston, Gillieston, Gol, Goulds, Grasstree,
Greenwell, Gunns, Haasts, Hamley, Heddon, Herdsmans, Doo, Jackeys, Illawarra, Lenah, Swanport,
Middleback, Monarto, Musselroe, Nicholls, Motton, Petcheys, Mcleay, Souttar, Kembla, Quamby,
Randalls, Shea-Oak, Shorewell, Kilkerran, Leonards, Stenhouse, Tods, Tolmans, Tooms, Tuntable, Wami,
Warrell, Barson, Playford, Yarcowie, Yallunda

Duplicate and redundant entries
Around 50,000 words appeared on more than one line (for example Übermenschen, Übermenschen's
and Übermenschen/M). Duplicate lines were merged into one entry with the combined affix flags.
87,622 plain entries that were already produced by another entry's affix flags
(usually plurals and possessives) were removed. No accepted words were lost.

Profanity suggestions
25 swear words and slurs were marked with the NOSUGGEST flag (!), which tells the spell
checker never to offer them as corrections. The flag was removed so that typos such as "fcuk"
or "cnut" can be corrected to the intended word, in keeping with the purpose of the dictionary.
Affected: arsehole, bullshit, bullshitted, bullshitter, bullshitting, chickenshit, cocksucker, coon, cunt, fuck, fucker, fuckhead, horseshit, kraut, motherfucker, motherfucking, nigger, shit, shitfaced, shithead, shitload, shitted, shitting, shitty, wop

Other changes
  - Version number updated to 3.1.0 in manifest.json.
  - Added a description to manifest.json.
  - Added a 3.1.0 entry to changelog.txt.
  - Dictionary sorted alphabetically (case-insensitive) with Unix line endings and an accurate
    word count on the first line.
  - The META-INF signing folder was removed because the Mozilla signature is invalidated by any
    change to the files. The .xpi needs to be uploaded to addons.mozilla.org to be re-signed
    before it can be installed permanently in release Firefox. For testing, load it via
    about:debugging > This Firefox > Load Temporary Add-on.
